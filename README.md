# GameCrafter Agent

> An LLM-powered Game Design Agent with Prompt Optimization and RAG.

## Overview

GameCrafter Agent is an advanced autonomous system designed to assist in game design and planning. It integrates real-time gaming industry news (via RAG) and an automated prompt-optimization pipeline to generate professional-grade game design documents.

## System Architecture

1. **Perception Layer (RAG):** Fetches real-time gaming trends using Tavily Search.
2. **Execution Layer (Planner):** Core generation engine powered by advanced system prompts (inspired by Devin & v0).
3. **Evolution Layer (Optimizer):** An automated prompt-engineering loop based on human-in-the-loop feedback.

## Tech Stack

- **Framework:** LangGraph, LangChain
- **AI/LLM:** OpenAI GPT-4 / DeepSeek
- **Search API:** Tavily
- **Environment:** Python 3.10+
